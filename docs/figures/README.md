# 技术报告图件

- `architecture.svg`、`architecture.png`：系统整体结构与板端、电脑、云端分工，对应报告图 1。
- `interfaces.svg`、`interfaces.png`：视频、模型原图、显示滤镜及外设接口，对应报告图 2。
- `workflow.svg`、`workflow.png`：最新帧调度、摔倒和手势分支、局部复核及主线程输出，对应报告图 4。

SVG 为可编辑矢量图，PNG 为高分辨率排版副本。修改 SVG 后需同步导出 PNG，再替换技术报告中的对应图片。正文、图号及图像显示尺寸无需重新排版。

图件统一采用白底、浅灰分区、深灰文字和蓝色连线，减少装饰性色块，兼顾彩色查看与黑白打印。

`ui_current.png` 为实际网页截屏。`photo_front.png`、`photo_angle.png`、`photo_wiring.png` 是明确标注的实物照片占位；提交前替换为自己的拍摄图片，并删除占位说明。

拍摄分镜见 [演示视频拍摄方案](../video_shooting_plan.md)。系统结构图也可用于视频中 00:25–00:38 的原理介绍。
